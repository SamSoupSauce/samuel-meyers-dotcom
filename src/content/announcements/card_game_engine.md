# Card Game Engine

I have built a framework by which card games are easily implemented, and can be played in a consistent manner. This is a side project, but if anyone enjoys it, that's great!

# Game Status

Currently, the only games implemented are:

* Baccarat
* Blackjack

Planned games include:

* Poker
* Hearts
* Spades
* Pinochle
* Gin Rummy
* Go Fish
* War
* 3-Handed Whist

But, this **works** right now. So i'm posting it.
