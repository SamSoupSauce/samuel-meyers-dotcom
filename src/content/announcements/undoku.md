# Undoku

I have built an **Actuaally** good Sudoku game. Due to my intense fondness for sudoku, I decided to do a bit extra with it. It generates actually new, pseudo-random sudoku puzzles. To do this, it assembles a valid puzzle, then shifts the numbers randomly, as long as the move would result in a valid puzzle. It then disassembles the puzzle, according to the level of complexity requested. It tracks which logical pattern is needed to calculate any given move. It assembles metrics, then displays a graph of the difficulty and how it's difficult. I went all in with this one. `<3`
